# 02 · 网络库

> 编号 02 · 总索引：[00-INDEX.md](00-INDEX.md)  
> 代码：`lib/screens/network_library_screen.dart`

网络库是 WebDAV 的浏览器：列目录、预览、把条目送进[下载队列](04-DOWNLOAD-QUEUE.md)或播放器。它**不是**曲库，也不代表本地有什么。

## 1. 核心约定：未下载 ≠「排队中」

- 用户没点过的远端文件处于 `TrackUiState.remote`：**不显示任何状态标签**，副标题写「点按下载」。
- 只有用户点按、多选或递归下载之后才入队，此时才出现「排队」「下载中」。
- 状态文案由 `lib/widgets/track_status_chip.dart` 统一给出：排队 / 下载中（带百分比）/ 就绪 / 播放中 / 错误；`remote` 返回空 widget。
- **不要**把「浏览时可见的远程文件」默认标成排队，也不要在播放路径上偷偷入队下载。

## 2. 行操作

| 操作 | 语义 |
|------|------|
| 点按音乐行 | 按设置「音乐点按行为」执行：默认**下载音乐**入队（提示「已加入下载」）；可选「播放（已缓存则播放，否则下载）」 |
| 点按已缓存音乐行 | 走同一个入队入口，命中缓存即直接就绪，不会重下 |
| 点按视频行 | 按设置「视频点按行为」执行：默认**打开视频**（远端流式播放，见 [06](06-VIDEO-PLAYBACK.md)）；可选「下载」。视频行**只有播放按钮，没有下载按钮** |
| 长按任意行 | 进入多选 |
| 行尾「⋮」 | 更多操作：下载到本地缓存、视频的「下载到系统相册」等 |
| 长按文件夹 | 递归下载整个目录里的音频 |
| 点按 `.cue` | 进 CUE 预览流程，确认后整组下载（见 [03](03-MUSIC-LIBRARY.md)） |

多选工具条：下载 / 全选（已经是全选时按钮变成「取消全选」并退出多选）。全选后下载 = 把当前目录里能下的全部排队，文件夹会被跳过。

## 3. 导航与返回键

- 进入子目录后按返回键 → 回父目录。
- 多选状态下按返回键 → 先退出多选。
- 已在根目录时按返回键 → 交给应用壳（切主页标签 / 挂后台）。
- 实现要点：网络库自带 `PopScope`，否则会被 `HomeShell` 的 `PopScope` 吃掉。壳层的返回语义见 [05 §3](05-AUDIO-PLAYBACK.md)。

## 4. 下载目标（这里只决定「去哪儿」）

| 条目 | 目标 |
|------|------|
| 音频 | 应用音频缓存，随后 ingest 进[音乐库](03-MUSIC-LIBRARY.md) |
| 视频（⋮ → 下载到系统相册） | 系统相册 `Movies/WebdavMediaManager`（MediaStore），不进音频缓存 |
| 普通文件 | **计划（未实现）**：下载到系统下载目录 / 指定文件夹 |

队列状态、进度通知与失败处理见 [04](04-DOWNLOAD-QUEUE.md) 与 [07](07-NOTIFICATIONS.md)。

## 5. 计划（未实现）：统一文件动作模型

网络库目前对「普通文件」的动作不完整，下列分块任务都**尚未实现**，实现前不要当成已支持能力：

- **T1** 统一文件动作模型与设置里的单击行为（决定点按走播放 / 下载 / 打开）。
- **T2** 下载至指定文件夹；普通文件默认「下载」。
- **T3** 多选工具栏的四种动作（下载 / 播放 / 分享 / 删除）统一到同一模型。
- **T4** 单文件右侧「更多」菜单与 T1 模型对齐。
- **T5** 修普通文件多选下载路径（与 T2 / T3 一起验收）。
- **T6**（可选，更后）音频串流复用视频侧已有的远端流式打开逻辑，避免另起一套；**不阻塞** T2–T5。

## 6. 相关代码

- `network_library_screen.dart`：目录列表、多选、`_enqueueMany`、CUE 入口。
- `lib/services/library_actions.dart`：入队与「已加入下载」提示等共用动作。
- `lib/services/webdav_service.dart`：列目录 / 读写 / 远端流式源。
- `lib/widgets/track_status_chip.dart`：状态标签唯一定义。
