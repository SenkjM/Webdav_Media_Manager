## 3. 下载队列

- [ ] **3.1** 任务列表显示文件名 + 状态 + 进度百分比
- [ ] **3.2** 视频任务显示「系统相册」标注
- [ ] **3.3** 取消 / 重试 / 删除 / 清除已完成都可用
- [ ] **3.4** CUE 组折叠成一行显示（如果你有 .cue）
- [ ] **3.5 「清除所有队列」需要二次确认**，确认后列表清空且系统通知消失
- [ ] **3.6 下载队列系统通知**（通道「下载进度」+「下载完成」）
  - 下载时通知栏出现**两条**通知（两级进度条）：
    - 「正在下载（第 k / N 个）」= **当前文件**的百分比 + 文件名（第一条进度条）
    - 「下载队列（N 个任务）」= **整批总量**百分比 + 「已完成 x / N」（第二条进度条）
  - 两条进度条都**真的在走**（不是一条灰线）——之前 `showProgress` 只给了上限没给当前值，所以永远是 0%
  - **N 只统计本次队列的任务**：队列里已有的「已完成」历史条目**不计入**（历史 20 条 + 新下载 1 个 → 「1 个任务」「0 / 1」）
  - 一次下多个 / 整个文件夹 → 仍然只有这两条通知，不会刷屏
  - **全部下完 → 两条进度通知消失**，未完成计数清零，弹出**新的**「全部下载完成 · 成功：x 个 失败：y 个」（有失败时标题变「下载结束（有失败）」）
  - 完成通知**不会自己消失**，点掉或下一次下载时被替换
  - 再开始一批新下载 → 计数**重新从 0 算**（不会带上上一批）
  - 关掉「设置 → 提示与通知 → 下载队列系统通知」→ 立刻清掉通知栏里这三条，之后完全不再出现
  - 通知是静音的，不响铃不震动

- [ ] **3.7 应用内消息（SnackBar）**
  - 设置 → 提示与通知 → 「提示显示时长」现在有 5 个选项：很短 / 默认 / 较长 / **点击才消失** / **关闭**
  - 选「点击才消失」→ 消息一直留着，**点消息本身**（不只是「知道了」按钮）就消失；左右滑也能滑掉
  - 选「关闭」→ 任何应用内消息都不再出现（下载失败的红条也不出现）

- [ ] **3.8 选择界面「全选」**
  - 音乐库网格 / 曲目列表 / 网络库 三处的多选工具条都有「全选」按钮（图标全选）
  - 已经是全选状态时，按钮变成「取消全选」并退出多选

## 8. 同步与备份（结构本轮重做）

- [ ] **8.1** 设置 →「同步与备份」能打开，分区块清晰（凭证 / 歌单 / 音乐库 / 一键 / 全部备份 / 本地导入导出）
- [ ] **8.1b 统一加密密钥必须由用户指定**（本轮修的严重问题）
  - 「WebDAV 凭证」区里有一栏「统一加密密钥（由你指定）」，可填写、可点「保存密钥」
  - 保存后**杀掉应用重开**，密钥还在（存在 Keystore，不是 SharedPreferences）
  - 加密与网盘密码**无关**：改掉该网盘账号的密码、或把凭证目的地换成另一个网盘，已同步的密码**依然能解出来**
    - 修复前：密钥就是「目的地网盘账号的登录密码」，改密码/换盘 = 之前同步的密码全部解不开
  - 密钥留空 = 密码明文存储（有明确提示）；清空后保存会从 Keystore 里删掉
  - 密钥**不会**写进备份 / 导出文件（换机恢复必须手动再输一次，输不了则密码留空、其余照常恢复）
  - 未设置密钥时，启动/定时的自动扫描会**跳过凭证拉取**（提示「凭证同步已跳过」），歌单照常合并
- [ ] **8.2** 「上传凭证」「下载凭证」可用（两者都使用上面那把密钥，不再用网盘密码）
- [ ] **8.3** 「立即同步歌单」可用
- [ ] **8.4** 「增量同步」/「全量同步」可用
- [ ] **8.4b 音乐库云端格式 = 一个 JSON 清单 + 二进制分片**（本轮重做）
  - 云端目录 `<同步根>/library/` 里应有：`index.json`（几百字节，只有文件名/片数/字节数/rev 区间）
    以及 `lib-*.wdmm` / `seg-*.wdmm` / `del-*.wdmm`
  - 下载 1 首新歌 → 只多出**一个很小的 `seg-*.wdmm`**，`index.json` 只多一行；**不会**重传整个曲库
  - 什么都没改时点「增量同步」→ 提示「**无变化（未上传任何内容）**」，且云端文件的时间戳不变
  - 曲目按**网盘名 + 路径**绑定：`index.json` 里**没有**网盘地址/用户名/密码，只有 `source_name`
  - 删掉一首（销毁）→ 多出一个 `del-*.wdmm`，但**重建前**云端旧分片里那首歌仍在（这是设计）
  - 同步页显示「云端分片：N 个（约 X KB）」；N ≥ 20 时提示「建议重建一次」
- [ ] **8.4c 重建云端音乐库**（会把删除真正落实）
  - 点「重建云端库」→ 可选用**每个分片歌曲数**（200/500/1000/2000）与**是否把封面写进分片**
  - 对话框实时显示「预计 N 个分片 · 含封面约 X · 不含封面约 Y」
  - 确认后云端只剩 `lib-*.wdmm` + 新的 `index.json`，旧 `seg-*/del-*` 被删除
  - 之前销毁的歌**不会**在重建后回来；另一台设备下次同步会跟着删掉它
- [ ] **8.4d 未绑定来源**
  - 把某个网盘改名（例如 `123pan` → `123pan2`）→ 音乐库里属于它的行应显示「**来源网盘未绑定**」
  - 点这些行不会下载/播放，而是红色提示「来源网盘未绑定（123pan）：请先在账号页添加或改名成这个名称的网盘」
  - 改回原名后恢复正常
- [ ] **8.4e 备份归档 = 同一套二进制容器**（本轮重做）
  - 设了口令导出 → 文件是二进制（不是 zip、不是明文 JSON），大小明显小于旧 zip
  - 清掉口令导出 → 仍是二进制容器（未加密）
  - 「导出可读 JSON（排障，不含封面）」→ 得到可读 `.json`，里面曲目带 `source_name`/`rev`，
    **没有**网盘地址与用户名，**没有**封面 base64
  - 两种文件都能「从本地文件导入…」恢复（导入端按魔数自动识别容器 / JSON）
  - 恢复后封面能显示（封面按「网盘名+路径」写回本机封面缓存）
- [ ] **8.4f 整理云端库**
