# 06 · 视频播放

> 编号 06 · 总索引：[00-INDEX.md](00-INDEX.md)  
> 代码：`lib/screens/video_player_screen.dart`、`lib/services/video_playback_service.dart`、`video_queue_controller.dart`、`lib/models/video_settings.dart`

视频与音频相反：**走远端流式播放**，不下载到缓存也不进曲库。下载到系统相册是另一条路（见 [02 §4](02-NETWORK-LIBRARY.md)、[04](04-DOWNLOAD-QUEUE.md)）。

## 1. 入口与设置

- 网络库点按视频行 → 按设置「视频点按行为」执行：默认**打开视频**（流式播放），可选「下载」。
- 流式缓冲上限可调（设置 → 视频播放）：默认 64 MB，范围 8–512 MB，下次播放生效。
- 可配置项：长按加速倍速（默认 2.0×）、左右双击手势、退出时二次确认、字幕位置 / 偏移 / 字号、后台播放开关。

## 2. 界面与手势

- **控件贴底**成一块卡片（播放控件 / 进度条 / 队列计数 / 倍速），不占画面中央；横屏时控件条有宽度上限并居中，时间文字带阴影保证亮画面可读。
- 单击画面：显示 / 隐藏控件，带淡入淡出（约 140 ms 进、240 ms 出）。
- 双击画面**中间**：播放 / 暂停。双击左 / 右：按设置的手势（默认 −10 s / +10 s），带缩放淡出反馈。
- 长按画面：按住期间临时加速，松手恢复。
- 倍速浮窗滑块 0.5×–3.0×，改完记住，下次沿用。
- 缓冲转圈**不遮挡中间双击区**（位置偏上），转圈出现时中间双击仍然有效。
- 顶栏在窄屏（竖屏 360 dp）不溢出：空间不够时把次要按钮收进「⋮」，日志里不应出现 `A RenderFlex overflowed`。
- 锁屏后控件隐藏、手势禁用，右上角留解锁按钮。

## 3. 播放列表（VideoQueueController）

- 用当前目录列表作种子**立即开播**，同时后台**深度优先渐进扫描**子目录；每扫完一个目录就合并进队列（按名称排序、去重），所以「上一个 / 下一个 / 自动连播」不必等扫描结束。
- 控件里有播放列表面板与计数（如 `3 / 27 · 扫描中…`），可点击跳转。
- 一个视频播完自动播下一个（同目录树内）。
- 播放超过 3 秒时「上一个」= 回到本视频开头（与主流播放器一致）。
- 切换视频时显示「正在打开 <文件名>」遮罩，避免画面定在上一帧像是卡死。

## 4. 后台、画中画与退出

| 操作 | 行为 |
|------|------|
| 主页键 | 挂后台继续播放（需开启「后台播放」） |
| 返回键 | **一定停止播放**；开启「退出时二次确认」时先问「确认关闭视频吗？」 |
| 画中画（PiP） | 小窗内没有任何控件，视频继续播 |

## 5. 与音频的互斥

- 视频开始播放 → 暂停音乐（音乐队列保留，退出视频后可在通知里继续）。
- 反过来点音乐 → 视频停止。
- 视频播放期间发的是**视频**媒体通知（不是音乐），见 [07](07-NOTIFICATIONS.md)。
