# 待修 Bug 与下载 / 串流计划

本文记录当前已知的开放问题，以及尚未排期的下载与播放处理计划，供开发者和 coding agent 查阅。除非另有明确需求，以下内容均为记录或规划，**不代表已经实现，也不要在此提交中实现功能**。

## 急需修复

| 问题 | 现象 | 优先级 |
|---|---|---|
| 普通文件多选下载不可用 | 对非音乐、非视频的普通文件进行多选后，下载按钮不能使用。 | 高：需修复 |
| 切后台后音乐下载失败 | 应用切到后台后，音乐下载报错 `fail host lookup`。 | 紧急：需尽快修复 |

## 计划中

### 「下载至指定文件夹」

将「下载至指定文件夹」作为**所有文件**的备选下载方案，默认使用系统下载文件夹。该方案用于让用户明确选择文件落盘位置，不改变现有音乐、视频等处理方式的既有语义。

计划包括：

- 在设置中现有的音乐 / 视频 / CUE 配置旁增加「下载至指定文件夹」配置项。
- 普通文件默认走「下载」处理。
- 文件处理方式统一考虑三种：**串流播放**、**缓存**、**下载**。

## 长远

- 之后尝试为**音频**增加串流播放，复用视频播放逻辑。
- 最终支持按不同后缀自定义处理方式，在**串流 / 缓存 / 下载**之间选择。
