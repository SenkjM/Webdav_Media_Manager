## 按文件处理设计（规划 / 设计，未实现）

本节是后续实现时必须遵循的四种动作与界面规则。处理方式可按具体后缀，也可按文件类配置；本设计不改变当前代码的行为，**目前仅记录设计，未实现**。

### 一、四种动作

| 动作 | 语义 |
|---|---|
| **流式播放**（stream） | 直接从远端读取并播放，不先将完整文件落到本地缓存。 |
| **缓存**（cache only） | 将文件保存到应用缓存；缓存完成后不自动开始播放。 |
| **缓存后播放**（cache then play） | 先将文件保存到应用缓存，缓存完成后再使用本地缓存播放。 |
| **下载**（download to folder） | 将文件下载到用户指定的文件夹（未指定时使用系统下载文件夹）。 |

### 二、设置与单击逻辑

- 设置中可按**文件后缀**（或文件类）选择单击行为。
- 可选行为固定为：**流式播放 / 缓存 / 缓存后播放 / 下载**。
- 用户单击文件时，执行该文件后缀（或文件类）当前配置的行为。
- 配置的粒度、默认值和后缀归类由后续实现任务另行确定；不得把本节规划误当作当前已支持能力。

### 三、单文件长按 → 多选

- 长按单个文件进入多选模式。
- 多选工具栏必须允许用户手动选择上述**全部四种动作**。
- 「流式播放」和「下载」可应用于所选的所有文件。
- 「缓存」和「缓存后播放」执行前仍必须按**音乐文件后缀**过滤：不符合音乐后缀的所选项过滤掉、不执行该动作，并弹窗提醒用户。
- 弹窗提醒应明确说明：该动作只支持音乐文件后缀，以及本次有非音乐文件被过滤；未被过滤的音乐文件仍可继续执行。

### 四、单文件右侧「更多」

单文件右侧「更多」菜单中的动作权限如下：

| 动作 | 可应用范围 |
|---|---|
| **流式播放** | 所有文件 |
| **下载** | 所有文件 |
| **缓存** | 仅音乐文件后缀 |
| **缓存后播放** | 仅音乐文件后缀 |

对非音乐文件打开「更多」时，仍可展示「流式播放」「下载」；「缓存」「缓存后播放」不可执行（可隐藏或置灰，具体交互由实现任务确定），不得绕过音乐后缀限制。
