# Webdav Media Manager

面向 Android 的网盘媒体管理器：浏览 WebDAV 远程目录，把音频下载到本地后再播放，不做网络流式播放。

适合把 NAS、网盘或自建 WebDAV 当作音乐库来源，在手机上离线收听。

当前仍在持续完善中，核心使用流程已可用。

## 功能

- **多站点账号**  
  可添加、编辑、删除多个 WebDAV 服务器，并在网络库中切换当前站点。支持新建文件夹、重命名与删除（权限不足时会提示）。

- **下载后再播放**  
  点击曲目会先加入下载队列，缓存完成后才用本地文件播放。支持后台排队、取消、重试与清除已完成任务；长按文件夹可批量下载其中的音频。

- **本地音乐库**  
  至少缓存过一次的曲目会进入本地库，并显示标题、艺人、专辑、曲序、碟号、封面与时长。可按专辑、作者、歌曲名浏览，也可按名称或专辑曲序排序。

- **CUE 分轨**  
  网络库可识别 CUE。标准 CUE 与对应音频一并下载后，会在音乐库中展开为分轨曲目，并按分轨点播放。

- **播放控制**  
  完整播放页、底部迷你播放条、临时播放队列。支持通知栏、锁屏与系统媒体控制（Android 13+ 需开启通知权限）。

- **歌单**  
  可从当前播放列表创建歌单，也可在本地编辑、删除。可选将歌单同步到 WebDAV，本地与远程按更新时间合并。清理音频缓存不会删除歌单。

- **缓存管理**  
  可查看缓存占用，单独删除某首音频，或按 1 天 / 1 周自动清理。正在播放或下载中的文件不会被清。清理音频不会删除曲库记录、封面与歌单。

- **备份与恢复**  
  可按站点备份账号、曲库、相关歌单与封面（不含音频缓存与下载队列）。支持口令加密，也可备份全部账号。恢复时按站点写回，不会串站。

- **曲库同步**  
  可对所选站点双向同步曲目索引、封面缩略图与歌单，不同步音频文件。

## 界面

侧边栏进入：音乐库、歌单、网络库、下载队列、设置、关于。

浅色界面，大封面正在播放页，底部为迷你播放条。

## 获取应用

- **Pre-release（内测）**：来自 `beta` 分支，Actions 里手动触发可自填版本号。
- **Release（正式）**：来自 `main` 分支，Actions →「Android Release (from main)」一键构建发布，可自填版本号与 versionCode。

包名 `com.senkjm.media_manager`。首次从旧签名换成当前内测签名时，需要先卸载再安装；之后可直接覆盖安装。
