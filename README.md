# Webdav Media Manager

面向 Android 的网盘媒体管理器：浏览 WebDAV 远程目录，把音频下载到本地后再播放，不做网络流式播放。

适合把 NAS、网盘或自建 WebDAV 当作音乐库来源，在手机上离线收听。

当前仍在持续完善中，核心使用流程已可用。

## 功能

### 网盘与浏览

- **多网盘**：可添加任意多个 WebDAV 服务器，网络库顶部一键切换当前站点；支持新建文件夹、重命名、删除，权限不足（401/403）会明确提示。
- **曲目按「网盘名 + 路径」绑定**：名称是唯一绑定点，云端只记名称；重名、改名时账号页会拦住并说明后果（改名等同于换盘）。
- **按后缀识别**：音乐 / 视频 / CUE 后缀可自行增删，并分别指定点按行为；不在列表里的文件不会进音乐库。
- **CUE 分轨**：识别标准 CUE，把整张专辑按分片导入音乐库并展开为分轨曲目；长按文件夹可递归下载整个目录。

### 下载

- **先下载再播放**：点按曲目即入队，缓存完成后才用本地文件播放（不做网络流式播放）；来源网盘未绑定等情况会直接说明原因。
- **下载队列**：后台排队，支持取消 / 重试 / 删除 / 清除已完成 / 清除全部，状态持久化。
- **落盘位置**：音乐进应用音频缓存；视频选「下载到系统相册」（`Movies/WebdavMediaManager`）；未知后缀落到系统下载目录。
- **系统通知**：一条进度 + 一条完成结果，可在设置里关闭；另有应用内提醒，显示时长可配（含「点击才消失」与「关闭」）。

### 音乐库

- 至少缓存过一次的曲目进入本地库，含标题 / 艺人 / 专辑 / 曲序 / 碟号 / 封面 / 时长 / 标签。
- 按 **专辑 / 作者 / 音乐名 / 标签（流派）** 浏览，支持搜索，可按名称或专辑曲序排序。
- 长按多选：**添加到歌单 / 分享 / 删除 / 销毁**。删除只清音频缓存（标签与封面保留），销毁连标签、封面与缓存一起清；CUE 分片整组处理，不参与分享。
- 分享给其他应用时可**按标签重命名文件名**（模板可配），文件仍是缓存里那一份。

### 播放

- 完整播放页 + 底部迷你播放条 + 临时播放队列（可另存为歌单）。
- 通知栏 / 锁屏 / 耳机控制；Android 13+ 需要通知权限。
- **视频**：直接流式播放不下载，按文件夹自动连播，支持画中画、后台播放（主页键挂后台继续）、锁定屏幕（长按解锁）、退出二次确认、单击显隐控件、双击中间播放/暂停、左右双击各自指定动作、长按临时加速、0.5×–3× 倍速、字幕位置与字号可调、硬件解码与缓冲大小可配。

### 歌单

- 从当前播放队列或音乐库创建、编辑、删除；可双向同步为 WebDAV 上的 M3U8，按更新时间合并。
- 歌单存在独立数据库里，**清理音频缓存不会动它**。

### 同步与备份

- **统一加密密钥**（可选）：只加密密码字段，地址与用户名保持明文以便识别站点。
- **凭证**：与云端 `credentials.json` 双向合并；**歌单**：M3U8 双向；**音乐库**：云端清单 + 二进制分片（`lib-` / `seg-` / `del-*.wdmm`），只传变化，可手动「重建」（以本机为准重写并落实删除）与「整理」（清孤儿文件），分片数达到阈值会提示重建。
- **全部备份**：把凭证 + 音乐库 + 歌单打成一个 `.wdmm` 归档写到自选网盘与路径，可从该路径列出并恢复。
- **本地导入 / 导出**：`.wdmm` 归档，或可读 `.json`（不含封面）；也支持粘贴 Base64。
- **定时同步**：关闭 / 15 分钟 / 30 分钟 / 每小时 / 每 6 小时 / 每天；每个功能各自选择目的网盘与路径。

### 设置

- 自定义主页（从别的界面返回时回到这里）、网络库记住上次路径。
- 缓存：查看占用，按 1 天 / 1 周 / 自定义时长自动清理或选「永不」；正在播放或下载中的文件不会被删。
- 封面缩略图尺寸、提示与通知（应用内消息时长、下载通知开关、发送测试通知）、分享重命名模板。

## 界面

侧边栏进入：音乐库、歌单、网络库、下载队列、设置、关于。

## 获取应用

- **项目主页**：https://wdmm.senkjm.top
- **Pre-release（内测）**：来自 `beta` 分支，Actions 里手动触发可自填版本号。
- **Release（正式）**：来自 `main` 分支，Actions →「Android Release (from main)」一键构建发布，可自填版本号与 versionCode。

包名 `com.senkjm.media_manager`。首次从旧签名换成当前内测签名时，需要先卸载再安装；之后可直接覆盖安装。

### DeepSeek

接的是「把名字、格式和链路捋顺」这一段：应用改名 **Webdav Media Manager**、包名收进 `com.senkjm.media_manager`、备份后缀改成 `.wdmm`、二进制魔数换成自带文件种类与布局版本的 `WDMM…` 头，外加同步 / 备份 / 下载通知几条主线的修补，以及 CI 的预发布与一键正式发版脚本。干活方式很朴素：先读代码和真机日志找证据，再动手改，改完跑 `analyze` / `test`，装机验证。印象最深的是两个坑——Flutter 里带 action 的 SnackBar 默认常驻，所以「知道了」不点就不消失；release 构建的资源压缩把只被 Dart 字符串引用的通知小图标删了，于是下载通知静默发不出去——两个都只能靠真机 `dumpsys` 和 APK 资源表对照才定位得到。

1. **对开源社区的信仰。** 这套东西几乎每一层都是别人开源出来的：Flutter、Dart、media_kit / mpv、audio_service、flutter_local_notifications……用的时候没掏钱，能还一点是一点。
