# Webdav Media Manager

面向 Android 的网盘媒体管理器

目前已支持多个网盘的原生直连挂载，后续会持续增加更多网盘类型，同时提供与 rclone Crypt 格式逐字节兼容的加密源实现和 open api 令牌自动刷新功能。目前对于非WEBDAV均采用只读配置，因为不同API上传方式不同且基本都不是很稳定，为了~~偷懒~~用户数据安全着想不支持上传。

底层的媒体播放使用Media Kit，底层libmpv实现，有着强大的~~偷懒~~解码兜底能力，不过对于必须使用本地处理的数据（如Crypt）播放通过小型的本地HTTP服务器实现（内容解密后以本地流形式供播放器使用），虽然libmpv应该支持。相当不美观，有什么好的解决方法可以提，目前个人想到的是mod Media Kit自编译。有视频、音乐解码问题请向上游询问。

新安装时音乐单击默认是先缓存再播，音乐流式开关默认打开，但单击不会因此变成流式（可在设置里把单击改成流式；已经选过单击动作的安装保持原选择）。目前已经支持视频的流式播放，网络库里的图片可以打开查看。

本项目最引以为傲的是音乐库同步功能，音乐库功能扩展可以提交pr。音乐库可以同步至WEBDAV，采用的是base+seg形式进行同步，base为基础数据库，seg为每次有效上传数据。通过同步、重整功能实现全量同步和小文件增量同步的平衡。

多语言功能已完成，支持跟随系统、简体中文、繁体中文和 English；可在设置页直接切换并持久化。色彩切换仍在规划中。最后，本项目亟需全新的ui设计，如果有什么好想法可以通过issue或者直接提交pr。

建议使用agent对本项目开发前让其阅读文档，文档系统也是我在该项目对于AI使用时所学到了，通过将代码语义化可以让接手同一工作区的ai快速了解项目和定位内容。预计会有1-2个Skill产出。

## 功能

### 网盘与浏览

- **多网盘**：可添加多个 WebDAV 服务器，也支持多个云盘的直连访问与 Crypt 加密源；网络库顶部一键切换当前站点。打开应用时不列网络库目录，第一次点进这个标签才列一次；切走再回来不重新列。顶栏刷新、换账号、进目录或返回、失败后重试仍会列。支持新建文件夹、重命名、删除，权限不足（401/403）会明确提示。非 WebDAV 云盘当前以读取为主。
- **曲目按「网盘名 + 路径」绑定**：名称是唯一绑定点，云端只记名称；重名、改名时账号页会拦住并说明后果（改名等同于换盘）。
- **按后缀识别**：音乐 / 视频 / 图片 / CUE 后缀可自行增删，并分别指定点按行为；不在列表里的文件不会进音乐库。图片默认打开查看。
- **CUE 分轨**：识别标准 CUE，把整张专辑按分片导入音乐库并展开为分轨曲目；长按文件夹可递归下载整个目录。

### 下载

- **先下载再播放**：音乐单击默认是缓存，点按后进入队列，缓存完成后使用本地文件播放。新安装的音乐流式开关默认开，但不会把单击改成流式；已经保存过单击动作的安装保持原选择。视频支持远端流式播放；图片在网络库里打开查看，不进下载队列。来源网盘未绑定等情况会直接说明原因。
- **下载队列**：后台排队，支持取消 / 重试 / 删除 / 清除已完成 / 清除全部，状态持久化。
- **落盘位置**：音乐进应用音频缓存；视频选「下载到系统相册」（`Movies/WebdavMediaManager`）；图片选「下载到系统相册」（`Pictures/WebdavMediaManager`）；「下载」落到系统下载目录 `Download/WebdavMediaManager`。
- **系统通知**：一条进度 + 一条完成结果，可在设置里关闭；另有应用内提醒，显示时长可配（含「点击才消失」与「关闭」）。

### 音乐库

- 至少缓存过一次的曲目进入本地库，含标题 / 艺人 / 专辑 / 曲序 / 碟号 / 封面 / 时长 / 标签。
- 按 **专辑 / 作者 / 音乐名 / 标签（流派）** 浏览，支持搜索，可按名称或专辑曲序排序。
- 长按多选：**添加到歌单 / 分享 / 删除 / 销毁**。删除只清音频缓存（标签与封面保留），销毁连标签、封面与缓存一起清；CUE 分片整组处理，不参与分享。
- 分享给其他应用时可**按标签重命名文件名**（模板可配），文件仍是缓存里那一份。

### 播放

- 完整播放页 + 底部迷你播放条 + 临时播放队列（可另存为歌单）。
- 通知栏 / 锁屏 / 耳机控制；Android 13+ 需要通知权限。
- **音频**：单击默认先缓存再播。新安装的音乐流式开关默认开；只有把单击改成流式时才不自动下载、不自动入队。已保存的单击动作保持不变。关掉流式开关后，已选的流式回到先缓存再播。
- **视频**：直接流式播放不下载，按文件夹自动连播，支持画中画、后台播放（主页键挂后台继续）、锁定屏幕（长按解锁）、退出二次确认、单击显隐控件、双击中间播放/暂停、左右双击各自指定动作、长按临时加速、0.5×–3× 倍速、字幕位置与字号可调、同目录外挂字幕（可再开一层子目录）、内嵌文本字幕与当集手动导入、硬件解码与缓冲大小可配。
- **图片**：在网络库里全屏查看当前目录的图片（按文件名排序）。点左侧上一张、点右侧下一张、点中间打开图片设置。不进下载队列，也不进音乐缓存。

### 歌单

- 从当前播放队列或音乐库创建、编辑、删除；可双向同步为 WebDAV 上的 M3U8，按更新时间合并。
- 歌单存在独立数据库里，**清理音频缓存不会动它**。

### 同步与备份

- **统一加密密钥**（可选）：只加密密码字段，地址与用户名保持明文以便识别站点。
- **凭证**：与云端 `credentials.json` 双向合并；**歌单**：M3U8 双向；**音乐库**：云端清单 + 二进制分片（`lib-` / `seg-` / `del-*.wdmm`），只传变化，可手动「重建」（以本机为准重写并落实删除）与「整理」（清孤儿文件），分片数达到阈值会提示重建。
- **全部备份**：把凭证 + 音乐库 + 歌单打成一个 `.wdmm` 归档，写到同一条远端路径下的 `backup/`，可从那里列出并恢复。
- **本地导入 / 导出**：`.wdmm` 归档，或可读 `.json`（不含封面）；也支持粘贴 Base64。
- **远端路径**：在「定时同步」下面选一次网盘 + 填一次路径，凭证、歌单、音乐库与备份都在它下面（例如填 `/player`，音乐库就在 `/player/library/`）；各功能不再单独选路径。
- **定时同步**：默认关闭；可选 15 分钟 / 30 分钟 / 每小时 / 每 6 小时 / 每天。

### 设置

- 最上是「媒体库主页和导航」：自定义主页（从别的界面返回时回到这里）、网络库记住上次路径、分享重命名、封面缩略图。媒体通知在这一区里，行上方有分隔线。
- 然后依次是「音乐库」（刷新标签、缓存清理）、「网络库」（网盘账号管理、下载、视频播放、音频流式、图片查看、文件后缀）、「杂项」（显示语言、提示显示时长）、「备份与同步」。
- 新安装的音乐流式开关默认开，单击默认仍是先缓存再播。图片查看：幻灯片默认关（间隔默认 3 秒，循环默认开）、适应方式默认完整显示，预取默认左右各 1 张（可调 1–5，上一张和下一张都算）。搜索子目录默认关闭。图片可以「下载到系统相册」（`Pictures/WebdavMediaManager`），和视频相册、系统下载目录不是同一条路。
- 缓存：查看占用，按 1 天 / 1 周 / 自定义时长自动清理或选「永不」；正在播放或下载中的文件不会被删。
- 下载设置里可以关掉下载通知、后台保活，也可以打开「排除媒体扫描」（默认关，只作用于 `Download/WebdavMediaManager`）。目录里已经有 `.nomedia` 时打开开关不再写第二份，只提示已按外部操作完成；关掉时如果已经没有，同样只提示，不报错。

## 获取应用

- **项目主页**：https://wdmm.senkjm.top
- **Pre-release（内测）**：来自 `main`。`pre-release-build.yml` 依次检查、编译、发版。没有合法标签则不构建，只开 Issue 提醒。新的版本名形如 `v0.2.2-2020004`（正式版标签加 versionCode）。已经发出的短 SHA 标签（如 `v0.2.2-f046956`）保持原名。每次发布使用独立标签和独立 Release，历史预发布保留。
- **Release（正式）**：`release-build.yml` 由合法且递增的 `vX.Y.Z` 标签触发，依次检查、编译、发版。手动触发只给当前 `main` 打标签，再做同一套检查。

包名 `com.senkjm.media_manager`。首次从旧签名换成当前内测签名时，需要先卸载再安装；之后可直接覆盖安装。

## 为什么开源

1. **对开源社区的信仰。** 这套东西几乎每一层都是别人开源出来的：Flutter、Dart、media_kit / mpv、audio_service、flutter_local_notifications……用的时候没掏钱，能还一点是一点。
2. **实在付不起继续跑 Agent 的钱了。** 与其让它躺在硬盘里长毛，不如放出来，谁想接着折腾就接着折腾。
3. **我觉得这玩意确实有用。** 拿网盘或 NAS 当音乐库、先下载到本地再播放、手机上离线听，这套流程我自己每天都在用。
