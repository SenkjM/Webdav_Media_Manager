核心能力

把远程目录变成可离线使用的本地媒体库，而不是又一个在线播放器。

网盘

WebDAV + 云盘直连

多个 WebDAV 站点任选，也可直连百度网盘、123 云盘、阿里云盘、115、TeraBox、网易云音乐等，顶部一键切换。支持建文件夹、重命名、移动、复制、删除；只读网盘按能力隐藏写入口。

加密

rclone Crypt 兼容

与 rclone / OpenList 逐字节兼容的加密源：文件名与内容解密正确，目录名加密、混淆模式、Base64 / Base32 / Base32768 编码齐全。只读挂载，可直接浏览、下载与播放。

下载

队列后台缓存

点按即入队，完成后才用本地文件播放。可取消、重试、清除；系统通知显示进度与结果。长按文件夹可递归下载整个目录。

曲库

专辑 / 作者 / 标签

缓存过的曲目进入本地库，带封面与元数据。CUE 分轨按整张专辑展开，分享时可按标签模板重命名，删除缓存不会毁掉曲库身份。

播放

本地优先，也可流式

完整播放页 + 迷你条 + 临时队列；通知栏 / 锁屏 / 耳机控制。音乐可选流式并预热后续曲目，视频流式支持画中画、后台播放、倍速、外挂与内嵌字幕、手势。

图片

目录内看图

在网络库里全屏查看当前目录的图片，点左侧上一张、点右侧下一张，支持幻灯片、适应方式与相邻预取；不进下载队列，也不进音乐缓存。

歌单

二进制双向同步

从队列或曲库创建歌单，双向同步为 WebDAV 上的二进制歌单，按更新时间合并；删除另记一包，避免别的设备把已删歌单传回去。

同步

曲库增量同步

音乐库走 base + 分片（lib- / seg- / del-*.wdmm），只传变化，可手动「重建」与「整理」；支持定时同步。

外观

浅色 / 深色 / 多语言

浅色、深色或跟随系统，并用一个主题色生成整套配色。语言支持跟随系统、简体中文、繁体中文与 English，设置页直接切换并持久化。

获取应用

包名 com.senkjm.media_manager。v0.2.3 已正式发布，核心流程可用。

  • Pre-release：来自 main，版本名形如 v0.2.3-2030002，每次独立标签、独立 Release，可覆盖安装。
  • Release：由合法且递增的 vX.Y.Z 标签触发，Actions 一键正式发版。
  • 非 WebDAV 云盘目前以读取为主，上传与云端写同步不开放。
  • 首次从旧签名换成当前内测签名时，需要先卸载再安装。
