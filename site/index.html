核心能力

把远程目录变成可离线使用的本地媒体库，而不是又一个在线播放器。

网盘

多 WebDAV 站点

任意添加 NAS、网盘或自建服务，顶部一键切换。支持建文件夹、重命名、删除，权限不足会明确提示。

下载

队列后台缓存

点按即入队，完成后才用本地文件播放。可取消、重试、清除；系统通知显示进度与结果。

曲库

专辑 / 作者 / 标签

缓存过的曲目进入本地库，带封面与元数据。CUE 分轨按整张专辑展开。删除缓存不会毁掉曲库身份。

播放

通知栏与锁屏

完整播放页 + 迷你条 + 临时队列。视频走流式播放，支持画中画、倍速、字幕与手势。

歌单

本地 + M3U8

从队列或曲库创建歌单，可双向同步为 WebDAV 上的 M3U8，按更新时间合并。

备份

凭证、库、歌单

统一加密密钥只保护密码。支持云端增量同步、.wdmm 归档备份，以及定时任务。

获取应用

包名 com.senkjm.media_manager。当前持续完善中，核心流程已可用。

  • Pre-release：来自 beta 分支，可覆盖安装。
  • Release：来自 main，Actions 一键正式发版。
  • 首次从旧签名换成当前内测签名时，需要先卸载再安装。
